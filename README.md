# Hi, I'm Suhani 👋

I build software projects across **software engineering, AI/ML, and generative AI**. My work includes computer-vision applications, semantic text matching, and full-stack products that connect web interfaces with AI services.

## Featured projects

### [CrediWise AI](https://github.com/Suhani0509/CrediWise-AI)
A credit-health planning application with a Next.js dashboard, Supabase integrations, scenario tools, and a separate FastAPI/LangGraph agent service. **Project prototype:** model-provider and database configuration are required for some workflows.

**Stack:** Next.js, React, TypeScript, Supabase, FastAPI, LangGraph, PostgreSQL

### [HireMind AI](https://github.com/Suhani0509/HireMind-AI)
A Streamlit prototype that compares job descriptions with uploaded resumes using sentence embeddings, heuristic rubric scores, candidate ranking, and CSV export. Scores are assistive signals, not validated measures of candidate quality.

**Stack:** Python, Streamlit, Sentence Transformers, scikit-learn, Pandas

### [Sign Language Interpreter](https://github.com/Suhani0509/Sign-language-Interpreter)
A camera-based hand-sign recognition prototype that uses a trained Keras model and hand tracking to build text from recognized signs, with a separate desktop interface and text-to-speech support.

**Stack:** Python, OpenCV, TensorFlow/Keras, Flask, cvzone

### [Deepfake Attack Detector](https://github.com/Suhani0509/Deepfake-Attack-Detector)
A Flask video-analysis prototype that samples frames, extracts image features, and classifies videos with a saved TensorFlow/Keras model. The repository includes separate experimental training code; performance claims should be based on reproducible evaluation.

**Stack:** Python, Flask, TensorFlow/Keras, OpenCV
